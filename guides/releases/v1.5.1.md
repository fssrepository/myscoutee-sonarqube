# myscoutee-sonarqube 1.5.1

MSC-129 adds the versioned GitLab CI/CD configuration for this repository.

- Normal builds run from commits; tests and publication are explicit manual jobs.
- Feature branches produce test candidates; release publication is restricted to master.
- Project settings live in `config/ci`; credentials remain in ignored local files and GitLab variables.
- The GitHub Actions conversion is retained as an inactive configuration example. Existing workflows keep their previous behavior.

This release changes build, deployment and supporting configuration. It introduces no intended application business-logic change. Runtime qualification and publication evidence are appended by the release job.
